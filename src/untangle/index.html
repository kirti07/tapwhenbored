What is this?

Untangle is a free online puzzle — dots connected by lines, some of them crossing. Every puzzle is randomly generated, so there's a fresh one to solve each time. No levels, no signup, no download.

How to play

  • Tap a movable dot to select it.
  • Tap an empty spot to move it there.
  • Untangle every line so none cross.
